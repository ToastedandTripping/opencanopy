## Stress test 1: pre-mortem

1. **Three months out, the corrected documentary still misrepresents unknown harvest dates.** This project's worst case is a false public environmental claim presented as measured, reproducible evidence. S0 deletes a chapter, but `origin/main:scripts/build-year-overlays.py:522–528` paints the undated baseline into every output frame; `chapters.ts` reuses those frames in the timeline, fire scene and ending. The new caption explains coarse cells, not unknown dates. S1-lite then fails its truth checks and L505–506 explicitly leaves S0 live indefinitely. The warning was the supposedly “dated 2025” frame being the same cumulative product that contains undated records. Suppress the affected overlays as the safe fallback and test a known undated-only area across all retained frames.

2. **The first instrumented release deadlocks the program or trains operators to ignore red guards.** M1a batch 0 must produce behavior failures, while C2 requires every preceding release to be green. Following both literally prevents the fix from shipping. Later, an actual red candidate similarly blocks the lane tasked with repairing it. A test-failure exception made informally under pressure defeats the release contract. Separate negative-control evidence from acceptance, with explicit states for baseline accepted, candidate rejected, rolled back and recovery permitted; exercise those transitions before the first behavior release.

3. **Rollback restores the homepage but strands active visitors.** A new page lazy-loads a new versioned frame after rollback; the restored old deployment may not contain that path. Keeping old assets in a new deploy only solves the forward direction. Historical deploys retaining their own files is useful only if the browser requests those historical deploy URLs or another retained asset store. The stated fixture starts with the old page and therefore misses the failing direction. Test old and new tabs, cold asset requests, two successive releases and rollback using the actual configured URLs.

## Stress test 2: load-bearing assumptions

- **Removing the baseline chapter removes undated imagery — confidence: disproven against nominated source.** The rasterizer unconditionally composites the baseline into every cutblock year. Consequence: S0's advertised safety fallback is false. Resolve before implementation.
- **Release-relative asset retention preserves active pages through rollback — confidence: low/unverified.** C1 offers two mechanisms without committing to request routing, and tests only the old-page direction. Consequence: blank frames or incompatible data after recovery. Resolve the hosting/retention mechanism before S1-lite's plan is approved.
- **Unique-area story totals preserve the existing shared definition of logged hectares — confidence: low/unverified.** The standing 2026-09-02 decision requires agreement across story, map and Phase B; the plan changes deduplication semantics without assigning the corresponding consumers. Consequence: individually tested public totals disagree. Resolve with a small overlapping/reharvest fixture and a shared derivation/version contract before rebuilding.
- **Resume-event freshness checks enforce a fifteen-minute display lifetime — confidence: low as specified.** A foreground tab need not emit either event at expiry; a count can also cross a Pacific date boundary while younger than fifteen minutes. Consequence: a stale “open now” civic claim remains visible. Resolve timer/date-boundary behavior before the count ships; the numberless fallback already exists.

## Stress test 3: inversion

The rejected “write every relay plan now” alternative would win only if downstream interfaces and data semantics were stable enough to avoid immediate obsolescence; they are not. However, a narrower version is already warranted: settle cross-relay release states, asset addressing and shared area semantics now, while leaving local implementation plans just in time. A sequential first wave would beat parallel lanes if S1-lite cannot deliver independently or coordinator recovery remains informal; S1-lite already gates M2 and B′, so the program should not claim creative independence implies schedule independence. Finally, suppressing the broken harvest imagery temporarily beats the chosen caption-only fallback because the source confirms that unknown dates remain baked into every retained frame.

## Overall verdict

**FAIL — block approval.** The program has the right scope and can retain its relay structure, but its interim honesty fix is contradicted by the actual raster pipeline, its release contract cannot distinguish deliberately failing controls from rejected releases, and its rollback and shared-data contracts leave material paths unproven. These are program-level defects that child-plan criticism cannot safely resolve independently. The accepted dollar exception is not a reason to reopen Lee's ruling; the required work is to make the remaining controls truthful and executable.
